# Tower Knight - 게임플레이 스펙

## 게임 개요

Tower Knight는 최대 4명의 플레이어가 협력하여 100층 타워를 정복하는 2D 횡스크롤 액션 RPG입니다.

## 플레이 화면

### 기본 화면 구성

```
┌─────────────────────────────────────────┐
│ [플레이어1] [플레이어2] [플레이어3]  ┃  Player Stats
│ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┫  • HP: ████░
├─────────────────────────────────────────┤  • MP: ██░░
│                                         │  • Level: 10
│          [ 타워 스테이지 ]              │
│                                         │  Current Floor
│   [적들]  [플레이어]  [아이템]         │  50 / 100
│                                         │

├─────────────────────────────────────────┤  [S] Attack

└─────────────────────────────────────────┘  [W] Skill 2
```

## 스테이지 구조

### 타워 구성

| 층 | 유형 | 특징 |
|----|------|------|
| 1-10 | 튜토리얼 | 기본 조작 학습 |
| 11-49 | 일반 스테이지 | 점진적 난이도 상승 |
| 50 | 중간 보스 | 보스 전투 |
| 51-99 | 일반 스테이지 | 고난이도 |
| 100 | 최종 보스 | 최종 보스 전투 |

### 스테이지 규칙

- **시간 제한**: 각 층 3분
- **패배 조건**: 플레이어 전원 쓰러짐
- **승리 조건**: 모든 적 처치 + 층 끝 도달
- **귀환**: 패배 시 마지막 체크포인트에서 재개

## 캐릭터 시스템

### 기본 스탯

```
체력 (HP)      - 생명력
마나 (MP)      - 스킬 사용 리소스
공격력 (ATK)   - 기본 데미지
방어력 (DEF)   - 데미지 감소
민첩성 (AGI)   - 이동/공격 속도
```

### 캐릭터 클래스 (예정)

| 클래스 | 역할 | 특징 |
|--------|------|------|
| 검사 | 전사 | 높은 공격력, 중간 방어력 |
| 궁수 | 딜러 | 높은 공격력, 낮은 방어력 |
| 마법사 | 범위딜 | 범위 스킬, 낮은 체력 |
| 성기사 | 탱커 | 높은 방어력, 치유 가능 |

## 전투 시스템

### 공격 메커니즘

```csharp
// 기본 공격
[A] 키: 근처 적 공격
데미지 = 기본공격력 + 무기보정 - 적방어력

// 스킬 공격
[Q], [W]: 스킬 사용
데미지 = 스킬 배율 × 기본공격력 - 적방어력
소비마나 = 스킬 마나 비용
쿨다운 = 스킬 쿨타임
```

### 예시 데미지 계산

```
플레이어 공격력: 50
무기보정: +10
적 방어력: 15

기본 공격 데미지 = (50 + 10) - 15 = 45
```

## 경험치 & 레벨

### 경험치 획득

```
적 처치: 적 레벨 × 10
보스 처치: 보스 레벨 × 100
미션 완료: 미션 난이도 × 50
```

### 레벨업 효과

```
레벨 상승 시:
- 체력 +10
- 공격력 +5
- 방어력 +2
- 모든 스킬 쿨타임 -5%
```

## 협동 플레이

### 멀티플레이 모드

| 모드 | 플레이어 | 연결 방식 |
|------|---------|---------|
| 싱글 | 1명 | - |
| 로컬 | 2-4명 | Wi-Fi / 블루투스 |
| 온라인 | 2-4명 | 인터넷 |
| NPC 동행 | 1명 + NPC | AI 파트너 |

### 팀 플레이 규칙

- 하나의 플레이어라도 전원 쓰러지면 게임 오버
- 플레이어 간 아이템 공유 불가
- 경험치/보상은 기여도에 따라 배분

## 리워드 시스템

### 스테이지 클리어 보상

```
기본 보상 = 클리어 난이도 × 100 골드 + 경험치

클리어 시간에 따른 보너스:
- 1분 이내: +50% 보상
- 1-2분: +25% 보상
- 2분 이상: 기본 보상

추가 미션 완료:
- 모든 적 처치: +20 골드
- 데미지 감소: +50 골드
- 팀 보너스: +10% 보상
```

### 월드 드롭

```
적 처치 시 확률로 드롭:
- 일반 아이템: 30%
- 희귀 아이템: 5%
- 에픽 아이템: 0.5%
- 골드: 100% (양은 적 레벨에 따름)
```
